# 本地作品集与创作工作台 — 产品规格说明书（Spec）

> **文档版本**：v0.3（明确外部 PDF 为只读特殊对象；增加图书出版排版与 PDF 成品预览）  
> **日期**：2026-11-18  
> **产品代号**：Local Portfolio Studio（暂定，不作为正式命名）  
> **状态**：产品构想／待评审  
> **标记说明**：`[已确定]` 来自现有产品构想；`[提议]` 是为使设计可落地而提出的方案；`[待决策]` 需要后续选择。

## 1. 产品概述

### 1.1 定位

一款**完全本地优先**、用于个人创作与作品归档的桌面软件。它将作品集管理、Markdown 文本编辑、图书式阅读与出版排版、摄影作品整理、博客与系列文章管理、外部 PDF 的只读归档预览及跨内容的标签／状态管理整合到统一工作台。

产品以用户可直接访问的**本地文件与文件夹**保存内容，不提供云端存储功能。即使未来停用本软件，用户仍可使用常规工具打开 Markdown、图片和导出的文档。

### 1.2 核心场景

1. 创建“文学作品”“摄影作品”等作品集合，向集合添加书籍、摄影集、博客集、系列文章集或纯文本文档等单品。
2. 编写一本由多个章节组成的书；在 Markdown 编辑、预览和双页书籍阅读界面之间切换。
3. 导入已有 Word 文档，按标题层级拆分为可编辑的 Markdown 章节；外部 PDF 则作为**不可编辑的特殊对象成员**原样收录和预览。
4. 管理一个摄影集的照片、顺序、说明和状态，例如为某张照片标记“待P图”。
5. 创建博客集，以发布日期、草稿状态和标签管理文章；创建系列文章集，按自定义顺序编排连载并提供前后篇导航。
6. 按标签或状态查找跨作品集合的章节、文章、照片、PDF 对象和单品；将自己创作的 Markdown 内容按指定书籍排版生成 HTML、Word 或 PDF，并预览 PDF 成品。

### 1.3 产品原则

- **本地可控** `[已确定]`：无云端账户、云存储或同步依赖；离线可用。
- **内容优先** `[已确定]`：Markdown 是可编辑文本内容的默认、持久化格式。
- **作品感** `[已确定]`：一本书在阅读态应当呈现为一本书，摄影集有适合照片的画廊界面；博客和系列文章应有符合其阅读方式的专属视图。
- **格式开放** `[已确定]`：支持导入、编辑和多格式导出；转换必须说明格式损失。
- **非破坏性** `[提议]`：导入原文件默认保留，不直接覆写；用户对工作副本进行编辑。
- **逐步扩展** `[提议]`：通过内容类型扩展未来的诗集、杂志、画册及其他作品类型。
- **PDF 边界** `[已确定]`：**不开发 PDF 编辑器**。外部导入的 PDF 是只读特殊对象，允许浏览、管理和标记；由 Markdown 排版生成的 PDF 仅用于预览和导出，不反向编辑 PDF 文件。

## 2. 信息架构与数据模型

### 2.1 层级

```text
工作区 Workspace（本地根目录）
└── 作品集合 Collection
    ├── 单品 Item：图书 Book
    │   ├── 章节 Chapter 01
    │   ├── 章节 Chapter 02
    │   └── 插图／封面／附件
    ├── 单品 Item：摄影集 Photo Album
    │   ├── 照片 Photo 01
    │   ├── 照片 Photo 02
    │   └── 说明／封面
    ├── 单品 Item：博客集 Blog
    │   ├── 博客文章 Post 01（Markdown）
    │   ├── 博客文章 Post 02（Markdown）
    │   └── 博客归档／发布日期／文章标签
    ├── 单品 Item：系列文章集 Article Series
    │   ├── 系列文章 Article 01（Markdown）
    │   ├── 系列文章 Article 02（Markdown）
    │   └── 自定义篇章顺序／系列目录
    ├── 单品 Item：纯文本文档 Document
    │   └── 文本内容 Markdown
    └── 特殊单品 Item：外部 PDF（Read-only PDF）
        └── 原始 PDF 文件（原样保存，只读预览）
```

- 一个工作区可包含多个作品集合。
- 一个作品集合可包含多个**不同类型**的单品，不强制按类型分组。
- 图书的章节、摄影集的照片、博客集的博文和系列文章集的文章统一称为“内容单元 Content Unit”。
- **博客集 Blog** 与 **系列文章集 Article Series** 在此版本都作为可放入任意 Collection 的 Item 类型；Collection 仍然允许混合类型。用户也可直接建立同名 Collection 整理多组博客或系列。
- **外部 PDF** 作为可放入 Collection 的特殊 Item 类型 `PDFDocument`，其正文**不进入 Markdown 编辑链路**。`[提议]` 图书等 Item 亦可引用或附带 PDF 对象，需确保原件不会因引用而被改写。
- 标签／状态可挂在**单品级**和**内容单元级**，两层互不覆盖。
- `[提议]` 支持拖放排序、封面、摘要、创建／修改时间。

### 2.2 基础字段

| 对象 | 必要字段 | 可选字段 |
| --- | --- | --- |
| Collection | id、名称、单品顺序 | 封面、描述、标签 |
| Item | id、type、标题、内容单元顺序 | 封面、作者、摘要、状态、标签、原始导入文件 |
| Chapter | id、标题、Markdown 路径、顺序 | 状态、标签、备注 |
| Photo | id、图片路径、顺序 | 标题、说明、状态、标签、拍摄元数据 |
| Post | id、标题、Markdown 路径 | 创建时间、发布日期、摘要、封面、状态、标签、slug、备注 |
| SeriesArticle | id、标题、Markdown 路径、系列内顺序 | 摘要、章节／分卷分组、状态、标签、上一篇／下一篇导航配置 |
| PDFDocument | id、标题、原始 PDF 路径、类型 `pdf` | 页数、来源、导入日期、封面缩略图、状态、标签、备注、文件校验信息 |
| BookLayoutProfile | id、名称、纸张尺寸、页边距、字体、字号、行距 | 章节起始规则、页眉页脚、页码、目录、扉页、分页规则、导出设置 |
| Tag | id、显示名称 | 颜色、描述 |
| Status | id、显示名称 | 颜色、排序、所属工作流 |

`id` 使用稳定标识符，避免重命名文件或标题导致关联丢失。

## 3. 界面与交互规格

### 3.1 作品库首页（Library）

依据现有手绘草图：**窄幅全局侧栏 + 主区卡片网格**。

- 左侧窄栏：个人入口／工作区入口、作品库、搜索／筛选、设置 `[提议]`。
- 主区：每个单品以带封面的卡片展示标题、类型及可选状态；允许以集合筛选。
- 创建按钮：新建集合、新建单品、导入文件。
- 卡片操作：打开、重命名、排序、编辑封面、添加标签、归档／删除。
- 空状态：提示“新建集合”或“导入作品”，不能强迫用户登录。

### 3.2 单品工作台（Workspace View）

依据手绘下半部分：**左侧层级导航 + 右侧大面积内容区**。

- 左栏：图书显示章节树；摄影集显示照片列表／分组；博客集显示年份／月份归档或文章列表；系列文章集显示有序目录与分组；普通文本显示文档结构或大纲；外部 PDF 显示页面缩略图／内置书签目录（若存在）。
- 主区：跟随内容类型切换编辑／呈现界面。
- 顶栏：标题、保存状态、编辑／预览模式、导入导出入口。
- `[提议]` 右侧属性面板（可折叠）：状态、标签、描述、文件信息；默认不占据大量空间。
- 拖动导航项可调整章节或照片顺序。

### 3.3 图书工作台

提供三类呈现形态：

1. **Markdown 编辑**：编辑原始 `.md`，支持快捷键及语法高亮。
2. **实时预览／分屏**：编辑与渲染并行显示；公式、图片、表格即时更新。
3. **书籍模式**：单页／双页、封面、章节跳转、纸张与边距设置、连续阅读。
4. **出版排版／成品预览** `[P1]`：对自己创作的 Markdown 图书选择专属排版配置（如纸张尺寸、字体、字号、行距、版心、页眉页脚、页码、章节起始页、目录和扉页）；基于排版结果生成**只读 PDF 成品预览**，检查真实分页、跨页图片与公式布局，确认后导出 PDF。排版参数保存在书籍元数据，不写回原始 PDF。

`[待决策]` 是否在书籍双页中**直接输入编辑**。初版优先保证“编辑 → 预览／书页”的可靠同步；原位双页编辑及输入后实时重分页可作为后续增强功能。此项不得阻碍未来扩展。

### 3.4 摄影集工作台

- 网格缩略图、单张聚焦浏览、全屏展示。
- 导入多张照片、拖动排序、填写照片标题／说明。
- 对单张照片添加状态（例如“待P图”）及任意标签。
- `[提议]` 显示基本图片信息（文件名、尺寸、格式、EXIF，若存在）。
- V0.1 **不内置修图引擎**；“待P图”用于工作流管理，照片可由外部软件处理后更新。

### 3.5 博客集工作台（Blog）

**定位**：管理一个持续更新的博客档案；即使不发布到网络，也能以博客页面的方式阅读全部文章。博客集是 Item，博文是内容单元。

- 新建、导入、编辑、删除、重命名和复制博文；每篇文章保存为独立 `.md` 文件，使用通用 Markdown／LaTeX 编辑器。
- **列表与归档**：按发布日期倒序展示文章；未设置发布日期的草稿单独显示。支持按年份／月份归档和标签筛选。
- **文章信息**：标题、摘要、封面、创建时间、修改时间、发布日期（可为空）、状态、标签；文章可保留历史发表日期，即使后续修订。
- **阅读视图**：博客首页／卡片或列表、单篇文章页、目录和文章内大纲；与图书的双页翻书模式区分。
- 支持博客集内文章搜索和批量状态修改 `[P1]`。
- **导出**：单篇 Markdown／HTML `[P0]`；整套博客导出为含索引页的本地 HTML 归档 `[P1]`，保留文章、图片和可离线导航的链接。
- `[提议／P2]` 静态网站目录、RSS 文件或前端站点生成；只生成**本地文件**，不包含在线托管、自动部署或云端同步。

### 3.6 系列文章集工作台（Article Series）

**定位**：整理有阅读先后关系的连续文章（教程、评论系列、长篇专题、研究札记等），由用户手动控制顺序。

- 新建、导入、编辑、删除和重命名系列文章；每篇文章保存为独立 `.md` 文件，支持 LaTeX、图片、代码块和其他通用 Markdown 功能。
- **系列目录**：左侧可拖放排序；支持分卷／分部／专题分组 `[P1]`，文章可以在组内调整位置。
- **文章阅读**：单篇阅读视图展示系列名称、当前位置、目录和**上一篇／下一篇**；支持从第一篇连续阅读。
- **元数据**：标题、摘要、顺序、状态、标签；可选发表日期，但默认以**系列顺序**呈现，不强制按时间排序。
- **导出**：单篇 Markdown／HTML `[P0]`；整套系列合并为 Markdown 或带导航的本地 HTML `[P1]`；按顺序导出 DOCX／PDF `[P1]`，延用文档转换规则。
- `[提议／P2]` 文章之间的引用链接、系列进度展示和系列封面／简介页。

### 3.7 两类文章集与图书的关系

- **图书 Book**：以章节和书页排版为中心，默认有完整书籍的连续阅读体验。
- **博客集 Blog**：以独立博文、发布日期、时间归档与主题检索为中心。
- **系列文章集 Article Series**：以文章先后关系、手动排序和篇间导航为中心。
- 三者**复用同一 Markdown／LaTeX 编辑能力与标签／状态系统**，但保留各自的导航、列表、阅读及导出界面。
- `[提议]` 未来允许将博客文章复制到系列中，或将系列汇编为图书；需要保留原文或显式选择复制／引用策略，避免隐式移动和内容丢失。

### 3.8 外部 PDF 对象工作台（只读）

**定位**：将现有的 PDF 作为一个特殊作品对象收录到本地档案馆，供浏览、检索和管理；该工作台**不包含任何 PDF 正文编辑、排版修改、章节切割、OCR 转可编辑文本或 PDF → Markdown 转换功能**。

- **导入**：选择本地 `.pdf`，将文件原样复制到工作区（或按用户选择引用外部路径 `[待决策]`），记录来源、导入时间、文件大小及可读取的 PDF 元数据。
- **显示**：直接以只读 PDF 阅读器打开；支持页面跳转、缩放、单页／连续滚动，以及 PDF 自带的书签目录（若有）；可选缩略图导航和文本搜索（仅针对已有可提取文本层）。
- **作品管理**：支持命名、封面展示、标签、状态和备注；这些信息保存在应用的 JSON 元数据里，**不得写入原始 PDF 文件**。
- **对象关系**：默认作为 Collection 中的特殊 Item；`[提议]` 允许某本图书把外部 PDF 作为附件／关联资料显示，但始终维持只读边界。
- **导出／外部打开**：允许复制原始 PDF、在系统默认 PDF 阅读器中打开；不提供“编辑 PDF”入口。
- **重要区别**：外部 PDF 的阅读预览与 Markdown 图书生成的 PDF 成品预览可以复用底层 PDF 阅读组件，但它们有不同的来源和保存规则。

## 4. 功能需求（Functional Requirements）

优先级：**P0** = 首版必须；**P1** = 首版后优先；**P2** = 后续扩展。

| ID | 功能 | 优先级 | 验收标准摘要 |
| --- | --- | --- | --- |
| FR-01 | 选择本地工作区 | P0 | 可以选择本地目录；重启后重新打开；不要求网络或账户。 |
| FR-02 | 集合／单品 CRUD | P0 | 能创建、重命名、打开、删除及排序集合和单品，混合类型共存。 |
| FR-03 | 图书章节管理 | P0 | 能新增、删除、重命名、重排章节；每章保存为可直接读取的 Markdown。 |
| FR-04 | Markdown 编辑 | P0 | 支持标题、列表、粗斜体、链接、图片、引用、代码块、表格、撤销／重做。 |
| FR-05 | LaTeX 数学公式 | P0 | 支持 `$...$` 行内及 `$$...$$` 块级数学公式的可靠渲染与编辑。 |
| FR-06 | 编辑／预览切换 | P0 | 编辑后预览同步；切换不应丢失内容或破坏原始 Markdown。 |
| FR-07 | 图书模式与章节侧栏 | P0 | 可按章节浏览完整书籍；提供单页／双页书籍呈现。 |
| FR-08 | 摄影集管理 | P0 | 可批量加入、浏览、排序照片，保存说明与元数据。 |
| FR-09 | 标签与状态 | P0 | 单品、章节、照片分别可添加／移除标签及状态。 |
| FR-10 | 全局筛选／搜索 | P1 | 可按标题、标签、状态检索跨集合内容，进一步支持正文全文搜索。 |
| FR-11 | 导入 Markdown | P0 | 现有 `.md` 可导入为独立文档或图书章节，保留相对附件引用。 |
| FR-12 | 导入 Word（DOCX） | P1 | 尝试按标题层级拆章；导入工作副本，保留原文件与内嵌图片。 |
| FR-13 | 外部 PDF 特殊对象导入 | P0 | PDF 作为独立只读对象原样保存；可以打开、浏览并关联标签／状态；不能编辑 PDF 正文。 |
| FR-14 | 导出 Markdown／HTML | P0 | 文档或完整书籍可导出；图片附件路径有效。 |

| FR-16 | 封面与主题样式 | P1 | 允许为单品设置封面，并保存书页排版偏好。 |
| FR-17 | 本地自动保存与恢复 | P0 | 编辑内容安全写盘，异常中断后的可恢复性经过验证。 |
| FR-18 | 书页内直接编辑 | P2 | 可在分页视图直接修改内容并触发可靠重分页；需专项性能验证。 |
| FR-19 | 博客集及博文管理 | P0 | 可创建博客集、增删改博文；独立 `.md` 落盘；草稿与发布日期可区分。 |

| FR-26 | 完整系列导出 | P1 | 可按用户定义的顺序合并 Markdown，或导出含目录的 HTML／DOCX／PDF。 |
| FR-27 | 系列分卷／分组 | P1 | 系列可建立分组，并对组和文章排序，导航树与导出顺序一致。 |
| FR-28 | 静态博客站点／RSS 生成 | P2 | 可选地生成本地静态网站和 RSS 文件，不引入云服务依赖。 |
| FR-29 | 外部 PDF 只读阅读 | P0 | 支持打开原 PDF、页面导航、缩放和读取 PDF 自带目录；所有内容标记保存在独立元数据。 |
| FR-30 | 图书专属排版配置 | P1 | 可保存每本书的纸张、字体、字号、行距、页边距、页眉页脚和章节分页规则。 |
| FR-31 | 图书 PDF 成品预览 | P1 | 对 Markdown 图书应用排版配置，生成可翻页核对的只读 PDF 预览，确认后可导出同版式 PDF。 |
| FR-32 | PDF 编辑边界保护 | P0 | 外部 PDF 不出现在 Markdown 或富文本编辑器中；任何标签与备注变更均不修改 PDF 文件字节。 |

### 4.1 Markdown 兼容范围

- 基线：CommonMark + 常用 GFM 扩展（表格、任务列表、删除线等）。
- 数学：行内 `$...$` 与块级 `$$...$$`；采用 KaTeX 或等效实现。
- 图片：使用相对文件路径；允许为图片指定替代文字及说明 `[提议]`。
- `[P1]` 脚注、目录生成、代码高亮主题、内部章节链接；博客文章和系列文章同样适用。
- 未识别的 Markdown／HTML 扩展应**尽可能保留原文**；不能默默删除未知语法。

### 4.2 导入语义

- **Markdown**：保留内容；复制／引用外部图片的策略可在导入时选择 `[待决策]`。可选择导入为独立文档、图书章节、博客文章或系列文章。
- **DOCX**：把文档标题层级映射成章节，图像提取到本地 `assets/`，转换后的 Markdown 作为编辑版本。
- **外部 PDF**：只导入为特殊 `PDFDocument` 对象；**不拆章、不解析为可编辑文本、不执行 OCR、不转换为 Markdown**。可读取原始书签／页数用于导航，可用已有文本层实现只读搜索（可选）。
- **PDF 对象元数据**：标签、状态、标题、备注等单独保存，原始 PDF 不发生改变。
- 导入文件转换有损时展示提示；绝不能静默覆写原文件。

### 4.3 导出语义

- Markdown 导出：保留每章源文件，或将图书合并为单个 `.md` `[提议]`；博客和系列支持单篇导出，系列 `[P1]` 支持按文章顺序合并。
- HTML 导出：正文、图片、公式可在离线浏览器中正常显示；博客集 `[P1]` 支持本地归档首页，系列文章 `[P1]` 支持目录和前后篇导航。
- DOCX 导出：保留标题层级、段落、图片及尽可能多的公式语义。
- PDF 导出：**仅对应用内 Markdown 等可编辑源内容**通过 HTML／分页引擎或文档转换流程生成 PDF；出版排版配置决定最终版面；支持先查看只读成品预览，再保存 PDF；系列文章集 `[P1]` 可按预设顺序汇编导出。
- 导出不反向改变原 Markdown 文件；也不修改已导入的外部 PDF 对象。

### 4.5 图书出版排版与成品预览

- **排版配置 Layout Profile** `[P1]`：每本书保存独立配置；预设模板可复用，用户可覆盖纸张、开本方向、页边距／版心、段落缩进、字体、字号、行距与段距。
- **书籍元素** `[P1]`：封面／扉页、章节标题、目录、页眉页脚、页码、奇偶页样式和章节从新页开始等规则；多页图片、表格、公式及脚注应尽量避免不合理断页。
- **成品预览** `[P1]`：由 Markdown 内容及 Layout Profile 生成与导出链路一致的 PDF；在内置只读阅读器中检查页序、分页与版面。需要时重新调整的是**源 Markdown 或排版配置**，不提供对 PDF 页内文字和图像的直接改写。
- **导出一致性**：预览与正式导出应使用相同的布局引擎和字体设置；如果由于字体缺失或系统环境造成差异，需要提示。
- **不影响外部 PDF**：此功能仅用于应用自创图书的成品预览及导出，与外部 PDF 的只读归档功能完全分离。

### 4.4 标签与状态

- **标签 Tag**：多选自由分类，如“人像”“散文”“待选入集”。
- **状态 Status**：指向进度，如“草稿”“待校对”“待P图”“已完成”；博客文章可以另外记录**发布日期**，以免将状态与时间混为一谈。
- 两者均为用户可维护的词条；`[提议]` 一项内容最多一个主状态、多个标签，未来支持多工作流。
- 状态必须可直接在图片／章节列表中辨识和批量修改 `[P1]`。

## 5. 本地数据与文件结构

**文件即作品内容，索引只是加速层。** 推荐初始目录结构：

```text
MyLibrary/
├── .studio/
│   ├── workspace.json          # 工作区配置
│   ├── index.sqlite            # [提议] 可重建的搜索索引
│   └── cache/                  # 缩略图与排版缓存，可删除
└── collections/
    └── literature/
        ├── collection.json
        └── items/
            ├── my-book/
            │   ├── item.json
            │   ├── chapters/
            │   │   ├── 01-intro.md
            │   │   └── 02-main.md
            │   ├── assets/
            │   │   └── cover.jpg
            │   ├── layouts/
            │   │   └── print-profile.json    # 图书排版配置
            │   └── originals/
            │       └── imported.docx
            ├── imported-pdf/
            │   ├── item.json
            │   └── originals/
            │       └── archived-book.pdf    # 外部 PDF：只读原件
            ├── blog-notes/
            │   ├── item.json
            │   ├── posts/
            │   │   ├── first-post.md
            │   │   └── second-post.md
            │   └── assets/
            └── article-series/
                ├── item.json
                ├── articles/
                │   ├── 01-introduction.md
                │   └── 02-next-topic.md
                └── assets/
```

文件结构可以在后续迭代中调整，但应遵循：

1. 内容以 `.md`、常见图片和 JSON 元数据直接落盘。
2. 搜索索引、缩略图及预览缓存可以全部重建。
3. 文件写入采用临时文件 + 原子替换等安全策略；重要操作可加入本地历史快照 `[P1]`。
4. 用户从外部修改文件后，软件应检测并重新载入；同一文件存在未保存修改时提示冲突 `[P1]`。
5. 删除操作进入应用内回收机制或系统回收站 `[提议]`，避免误删除作品。
6. 博客日期／文章状态与系列阅读顺序存放在 `item.json` 或内容单元元数据中，不依赖文件名推断；文件仍可直接打开。
7. 外部 PDF 的原始字节保持不变；标签、状态、笔记、缩略图、书签 UI 状态与阅读进度均存放在独立元数据或缓存中。
8. 图书的 `Layout Profile` 是排版参数，不代替 Markdown 正文；生成的 PDF 成品默认属于可重新生成的导出文件，不与外部导入 PDF 混淆。

## 6. 技术方案建议（非最终选型）

| 层次 | 候选方案 | 角色与注意点 |
| --- | --- | --- |
| 桌面壳层 | Tauri 2 | 本地文件访问、桌面窗口、离线运行。 |
| 前端 | React + TypeScript | 组件化首页、工作台、照片画廊、属性面板。 |
| Markdown 源码编辑 | CodeMirror 6 | 高亮、搜索、快捷键、撤销栈等。 |
| 所见即所得编辑 | Milkdown（候选） | 文档结构编辑；需验证 Markdown 往返保真。 |
| Markdown 渲染 | Remark／Rehype | 解析与 HTML 渲染管线。 |
| 数学公式 | remark-math + KaTeX | 数学语法识别和公式渲染。 |
| 书籍分页与出版排版 | Paged.js（候选） | HTML 到书页布局；需验证字体、页眉页脚、目录与预览／导出一致性。 |
| PDF 只读阅读 | PDF.js（候选） | 预览外部导入 PDF 和 Markdown 生成的 PDF 成品；不接入 PDF 编辑工具。 |
| 格式转换 | Pandoc（候选） | Markdown／DOCX／HTML 等转换；需考虑打包、安装及许可。 |
| 本地索引 | SQLite（可选） | 全文搜索与标签筛选；不承载唯一内容副本。 |
| 博客／系列工作台 | React 组件复用通用 Markdown 编辑器 | 时间线与目录是数据呈现层，不额外引入独立正文格式。 |

**编辑器边界约束**：以磁盘 Markdown 为可信源，富文本内部树及 HTML 页面为编辑／渲染模型。必须测试“Markdown → 所见即所得 → Markdown”往返，避免丢失未知语法、注释、LaTeX 或自定义块；遇到无法无损支持的内容允许退回源码编辑。

## 7. 非功能需求

- **离线与隐私**：不要求登录，不自动上传文档、图片、编辑行为或使用数据。
- **可靠性**：崩溃、断电、重复打开与导入失败时尽量不损伤原始文件；重要操作提供恢复路径。
- **可移植性**：将工作区文件夹整体移动到其他路径后仍可恢复工作；尽量使用相对路径。
- **性能**：大图列表使用缩略图缓存与虚拟滚动；长篇书籍按需分页而非阻塞整个编辑器。
- **可访问性**：键盘可操作核心流程；字号可调整；图书阅读支持缩放。
- **平台**：`[待决策]` Windows 优先，未来是否支持 macOS／Linux。
- **安全**：导入 HTML／Markdown 渲染必须净化危险脚本及不受信任资源；明确处理外部链接。

## 8. 核心用户流程与验收场景

### AC-01：从零创建图书

1. 选择本地文件夹，创建工作区。
2. 新建“文学作品”集合，再新建“图书”单品。
3. 新建两章并写入 Markdown 和数学公式。
4. 在编辑与书籍双页模式之间切换，左栏可跳转章节。
5. 关闭并重新打开应用，文本、章节顺序、标签和页面设置保持一致。

**通过条件**：章节确实存为可外部打开的 `.md`，公式渲染正确，重新打开无数据丢失。

### AC-02：摄影集标记流程

1. 新建“摄影作品”集合与“摄影集”单品。
2. 批量导入照片并调整排列顺序。
3. 为一张照片标记“待P图”，为另一张标记“已完成”。
4. 重新打开软件，标记及照片顺序保持一致。

**通过条件**：图片原始文件仍然可读，标签／状态无需修改图片像素或文件本体。

### AC-03：导入带章节的 Word

1. 导入含标题层级的 DOCX。
2. 软件生成章节候选，用户可以确认或调整。
3. 对成功提取的章节编辑文字，另存为 Markdown 工作副本。
4. 导出新文档，并保留原始输入文件。

**通过条件**：能明确区分 DOCX 原件、Markdown 工作副本和导出文件；导入质量不佳时给出可理解的提示。

### AC-04：跨作品的标记检索

1. 对不同集合中的一章和一张照片赋予各自状态。
2. 从作品库的筛选入口按状态或标签查询。
3. 能直接定位对应章节或照片。

**通过条件**：单品级与内容单元级标记不会相互覆盖；博文和系列文章同样可以作为内容单元独立检索。

### AC-05：创建博客并整理归档

1. 在任意 Collection 中新建“博客集”单品。
2. 新建两篇文章：第一篇设置发布日期，第二篇保持草稿状态、不设置发布日期。
3. 使用 Markdown 和 LaTeX 编写内容，并给第一篇添加“随笔”标签。
4. 查看博客首页／归档：第一篇按发布日期显示，第二篇在草稿区显示。
5. 关闭后重新打开，检查文章内容、日期、状态和标签是否完整。

**通过条件**：每篇博文为独立 `.md`，本地可读；草稿不会被错误归入已发布时间线；日期与标签持久保存。

### AC-06：编排连续系列文章

1. 在任意 Collection 中新建“系列文章集”单品。
2. 新建三篇文章，用 Markdown／LaTeX 编辑。
3. 把第三篇拖到第一篇前面，并给其中一篇标记“待校对”。
4. 从系列目录依序打开文章，使用“上一篇／下一篇”切换。
5. 退出重开后验证排序、内容与标记均保留。

**通过条件**：阅读顺序按照用户设定，和文件创建时间及发表日期无关；目录与篇间导航一致。

### AC-07：外部 PDF 只读对象

1. 从本地导入一份已有排版的 PDF，将其添加到 Collection。
2. 点击 PDF 卡片，使用只读阅读器查看页面和原有书签（若存在）。
3. 为该 PDF 设置标签“资料”、状态“待整理”和一段备注。
4. 关闭重新打开应用，继续阅读。
5. 比较导入前后 PDF 文件的校验值。

**通过条件**：PDF 仍保持原始排版；未出现 PDF 文本编辑／转换入口；标签和备注都持久保存，PDF 原始字节没有变化。

### AC-08：Markdown 图书的专属排版与 PDF 成品预览

1. 创建包含多个 Markdown 章节的图书，插入图片、公式和目录。
2. 调整该书的出版排版配置（纸张尺寸、字体、版心、页眉页脚、页码等）。
3. 生成只读 PDF 成品预览，检查章节起页与多页布局。
4. 调整 Markdown 或排版配置，重新生成预览。
5. 导出正式 PDF。

**通过条件**：正式 PDF 与最终成品预览使用同一版式；整个过程中 Markdown 是可编辑源，PDF 仅供阅读与导出，未提供编辑 PDF 页面本体的能力。

## 9. 版本范围与里程碑

### M0：交互原型与技术验证

- 完成首页卡片网格、集合视图、图书章节侧栏、摄影画廊、博客时间线、系列文章目录和外部 PDF 只读对象页的可点击原型。
- 验证 Markdown 双向编辑、数学公式、双页书预览、PDF.js 只读阅读和本地文件系统读写。
- 专项验证含复杂 LaTeX、图片和扩展 Markdown 的转换保真。

### M1：本地可用的核心版本（P0）

- 本地工作区、集合／单品管理、图书章节、摄影集、博客集与系列文章集。
- Markdown 源码编辑、公式渲染、编辑／预览切换、基础双页书阅读。
- 外部 PDF 作为特殊 Item 导入、只读查看与标签／状态管理；绝不提供 PDF 编辑。
- 单品／章节／照片／博文／系列文章的标签与状态。
- Markdown 导入、Markdown／HTML 导出、本地自动保存。
- 博客按发布日期归档、草稿分区；系列文章自定义排序、目录及上一篇／下一篇导航。

### M2：格式与内容管理（P1）

- DOCX 导入转换与分章辅助；Markdown 图书的 Word／PDF 导出及专属出版排版配置、PDF 成品预览。
- 全局搜索／筛选、封面主题、照片批量操作、本地历史恢复。
- 整套博客离线 HTML 归档、系列文章合并导出、系列分卷／分组。
- 优化图书样式、目录和大文档性能。

### M3：高级出版体验（P2）

- 书籍双页内直接编辑、编辑后实时重分页。
- 高级排版模板、出版物细节控制、更多作品类型；**不包含 OCR 转写、PDF → Markdown 或 PDF 编辑功能**。
- 博客静态站点目录／RSS 离线生成；文章跨类型复制或引用策略。

## 10. 尚待决策的问题

1. **平台**：首版仅 Windows，还是同步兼容 macOS／Linux？
2. **编辑模式**：书籍双页中直接编辑是否必须进入 M1，还是允许 M1 先支持 Markdown 编辑 + 双页阅读？
3. **导入策略**：默认复制外部图片／文件进入工作区，还是允许仅引用原路径？
4. **状态系统**：每个内容单元只允许一个主状态，还是可同时拥有多个状态？
5. **外部 PDF 附件关系**：首版仅允许 PDF 作为 Collection 的特殊 Item，还是同时允许挂在图书 Item 下作为只读附件？
6. **图书样式**：纸张尺寸、字体、行距、页眉页脚与页码已列为出版排版需求；待决定首版提供多少预设，以及自定义到什么程度。
7. **项目名称与视觉语言**：是否采用独立品牌名？卡片式作品库和实体书界面采用怎样的设计系统？
8. **博客集与系列文章的复用方式**：同一篇文章可同时归属于博客集与系列文章集吗？初版默认各自独立；跨类型复制或引用需确定冲突处理规则。
9. **博客发表语义**：是否需要“已发表／未发表”专用字段？初版用可空发布日期加可自定义状态区分。
10. **博客导出定位**：未来是否需要静态网站生成、RSS 或自定义主题？本期只确定离线本地归档，网络发布不纳入产品范围。
11. **系列层级**：分卷／分部／专题是否需要任意嵌套？初步先提供一级分组 `[P1]`。
12. **PDF 引用方式**：导入时默认复制到工作区，还是允许保持只读外部路径引用？
13. **出版预览刷新**：排版参数修改后手动刷新 PDF 成品预览，还是支持后台增量更新？初版优先保证稳定与一致性。
